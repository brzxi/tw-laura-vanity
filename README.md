# تسريحة لورا — Laura Vanity (Salla Twilight Bundle)

مكوّن تسريحة تفاعلي لمتجر لورا بوتيك: صورة التسريحة بالشعار، وكل درج ينزلق عند المرور ويفتح رابط قسمه.

- `src/components/laura-vanity/index.ts` — المكوّن (Lit)
- `twilight-bundle.json` — إعدادات المكوّن في محرر الثيم (العنوان، الصورة، الأدراج وروابطها)
- `assets/` — صورة التسريحة الافتراضية

```
pnpm install
pnpm build
```
